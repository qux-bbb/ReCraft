# 路线图（DESIGN §14 摘要）

> 状态更新于 M3 完成、M4 进行中。详细设计见 [DESIGN.md](DESIGN.md)。

| 里程碑 | 内容 | 状态 |
|---|---|---|
| M0 | 工作区/存储/PE 导入/反汇编基线、评测脚手架 | ✅ 完成 |
| M1 | 函数发现 + 字符串/xref/API 标签、CLI/UI 基线、undo/redo | ✅ 完成 |
| M2 | IR/lifter 语义覆盖、L1 结构化、L2 签名/ABI/类型、MCP 只读工具 | ✅ 完成（corpus 覆盖 97.1%、结构化 93.1%） |

## 近期优先项

1. **M4 收尾**：干净 Win10/Win11 虚拟机安装/卸载验证、代码签名、预览材料（README 截图/
   卖点/FAQ）。
2. **真实样本结构化率**：notepad 62.4% → 目标 70%+（do-while、break/continue、不可归约
   子图拆分）。
3. **类型系统**：真正 SSA/phi、跨函数原型传播、结构体数组布局。
4. **打包**：NSIS 安装器实测、自动更新策略。

## 明确不做（v1）

- IDA 数据库/插件/IDAPython 兼容。
- 保证伪代码可编译。
- 云端多租户/在线协作。
- 样本上传或云端分析（AI 默认离线，显式配置才会发送脱敏 prompt）。
