## M3 剩余

1. **AI provider 完善**：prompt 模板库、固定 prompt 回归集与命名准确率评测；缓存/审计接线
   到 CLI/UI；真实 OpenAI 账号与 Ollama 的端到端冒烟。
2. **UI proposal 面板增强**：批量勾选、before/after diff、按置信度过滤、键盘操作；证据地址双向高亮。
3. **其余写工具**：`define_function` 的交互式 UI；原型/结构体声明解析为表达式类型传播。
4. **自然语言查询**：转 MCP tool 调用；伪代码润色（标注 AI 修改，不覆盖原始输出）。
5. **1 GiB 全量门禁**：interactive <5 s、import <60 s、≤512 MiB 稳态内存的自动测量。
6. **打包收尾**：安装器在干净 Win10/Win11 实测、代码签名、自动更新（DESIGN 后续版本）。
