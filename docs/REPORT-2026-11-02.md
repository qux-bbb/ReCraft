## 1. 本阶段新增/修复的变换

| 变换 | 效果 | 安全性依据 |
|---|---|---|
| `collapse_nested_if_wrappers` | `if (a) { if (b) { … } }` → `if (a && b) { … }` | 内层 `if` 必须是外层**整个**块；两侧均无 `else`；含顶层 `\|\|` 的一侧加括号；两侧条件相同则合并为一个 |
| `merge_accumulations` | `rax = &var_38; rax += 8;` → `rax = (&var_38 + 8);` | 相邻两行、同一目标、增量是常量、右侧无函数调用、无窄类型强转（寄存器加法是 64 位） |
| 常量折叠支持子寄存器宽度 | `eax = 0x5a4d; if (word_140000000 != ax)` → `if (word_140000000 != 0x5a4d)` | 仅当常量按比较宽度截断**不改变数值**；`ax`/`al`/`r8w`/`r8b` 等 16 组别名 |
| 常量折叠支持复合赋值 | `rdx = 0x140000000; rcx += rdx;` → `rcx += 0x140000000;` | 仅在 `+= -= &= \|= ^= *= <<= >>= /= %=` 的**右操作数**、且与寄存器完全相等时 |
| **修复：跨块常量折叠** | `eax = 0; do { edx += eax; … }` 曾被折成 `edx += 0` 并删掉 `eax = 0;` | 赋值与使用必须在**同一花括号层级**；复合赋值 `eax += 2` 视为**读**而非覆盖 |

最后一条是正确性缺陷修复：常量被推进到更深的块（循环体内）后，取到的不是常量而是**循环携带值**。
notepad 的 L2 行数因此从 29 651 略增到 29 667——**错误的删码消失了，这个方向的数字不值得追求**。

## 5. 仍然存在的限制（未改变）

1. **多入口循环**（不可规约流图）：notepad 452 处 `goto` 中 161 处是"向后跳进 `if` 分支"，
   只能靠 CFG 层的守卫提升/节点复制消除；细节、最小复现与实现地图见 `docs/NEXT.md`。
2. Go 的 263 个回退函数主要来自"内层循环跳出父循环"与运行时内部（`runtime.mapassign*`、`internal/strconv` 等），C 没有带标签的 `break`，用 `goto` 是**忠实**
   的表达，不打算强行改造。
3. 局部变量仍是 `var_XX`：命名需要跨基本块的数据流分析（当前只有栈参数与结构实例命名）。
4. 常量条件（`if (0x302 >= 0)`）不自动求值：删码依赖常量传播的正确性，风险高于收益。

```powershell
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
target\debug\recraft.exe lint <project> [--level l1|l2] [--json]
target\debug\recraft.exe golden <project> --dir tests/golden/<set> [--limit N] --check
target\debug\recraft.exe metrics <project>
RECRAFT_PROFILE=1 target\debug\recraft.exe decompile <project> --addr <addr> --l2
```

阅读顺序固定为 **lint → golden diff → metrics**：先确认结构仍合法，再看形状变化是否符合预期，
最后看结构化率与覆盖率是否提升。三层都解释得通才提交。
