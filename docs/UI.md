# UI 设计基线（W6 现代化）

参照对象是 [ArtCraft](https://getartcraft.com/) 授予观感的那一套：**近黑的低对比表面、
发丝级 1px 边框、克制的一个强调色、大留白与圆角卡片**。目标不是把 ReCraft 变成另一个
产品，而是把"像工具"的观感换成"像产品"的观感，同时不牺牲 IDA 用户依赖的信息密度。

## 1. 表面分层

| 层 | 用途 | Dark | Light |
|---|---|---|---|
| `surface_0` | 代码视图 / 列表底 | `#0E1013` | `#FFFFFF` |
| `surface_1` | 面板、侧栏、标题栏、状态栏 | `#14171B` | `#F5F7FA` |
| `surface_2` | 卡片、弹层、菜单、输入框 | `#1A1E24` | `#EDF1F6` |
| `border` | 发丝分隔线 | `#262B33` | `#D6DCE4` |
| `border_strong` | 聚焦/选中描边 | `#333A45` | `#B7C0CC` |

规则：**只用 1px 边框分层，不用阴影**（弹层除外）。相邻两层至少差一档亮度。

## 2. 文字

| 角色 | Dark | Light | 字号 |
|---|---|---|---|
| `text` | `#E4E7EB` | `#161A20` | 13 |
| `muted` | `#98A2B3` | `#5A6472` | 11–12 |
| 地址/链接 `accent` | `#40CDE0` | `#0E7490` | 13 |

标题 15、空状态大标题 22。等宽只用于反汇编/伪代码，正文不再混入等宽。

## 3. 强调色

只有一个：**青** `#40CDE0`（与图标里的扫描线同色）。所有可点击、选中、拖拽高亮都用它，
`danger` `#F87171` 与 `success` `#4ADE80` 只用于破坏性操作与完成态，不做装饰。

## 4. 间距与圆角

- 间距刻度：**4 / 8 / 12 / 16**，面板内边距 12，控件间距 8，行高 22。
- 圆角：控件 **6**、卡片 **10**、窗口/弹层 **12**。
- 顶部工具栏高 34，状态栏高 24；两者都贴 `surface_1` 并用 `border` 与内容区分隔。

## 5. 交互态

- hover：表面升一档（`surface_1 → surface_2`），不改变文字色。
- active/按下：强调色 12% 叠在表面之上。
- 选中：强调色 18% 填充 + 1px `accent` 描边；不再用"整行反色"。
- 焦点：`border_strong` 1px，键盘可达区域必须有。

## 6. 落地顺序（W6）

0. **已完成**（2026-11-14）：主题令牌 + 欢迎页空状态（大标题、青色主操作、最近项目卡片）；pply_theme 已把三层表面、6/10/12 圆角、强调色选择态、弹层柔和阴影写进 Visuals。
1. **主题令牌**（本轮）：`Palette` 扩展 surface/border/muted/accent，`apply_theme` 统一
   控件圆角、描边、选择色、超链接色、弹层阴影；
2. **框架化**：顶栏/状态栏/侧栏改为卡片化分组，命令区收敛成"工具条 + 溢出菜单"；
3. **空状态与引导**：没有项目时给大标题 + 三个入口（导入、打开、示例），替代灰色空白；
4. **图标迭代**：见 `docs/ICON.md`，随 0.4.0 一起出包；
5. **可访问性**：对比度 ≥ 4.5:1（正文）、所有仅图标按钮补 tooltip、键盘焦点环。

验收方式：`cargo test -p recraft-ui`（137 项）、`cargo check`、0.4.0 打包后人工过一遍
主界面（导入 → 分析 → 反汇编 → 伪 C → 交叉引用 → 设置）。
